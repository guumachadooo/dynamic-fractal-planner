## Core Rules
- **Reply:** user's language | ~8-12L routine (expand ONLY when requested) | report verified output ONLY.
- **Agent Files (Symbolic Telegraphic EN — mandatory):** ALL plugin/memory/plan files (`PROJECT_HISTORY.md`, `SAVED_IDEAS.md`, `EXTRA_REQUESTS.md`, `HANDOFF.md`, `BUILD_LESSONS.md`, `EXTERNAL_AI_SYNC.md`, `TASK_PLAN.md`, `AGENTS.md`/`SKILL.md`, `plan_tool.py` args) MUST use lossless dense symbolic EN regardless of chat language (never mangle user-facing UI/public docs): drop articles/copulas/filler (`a/the/is/please/in order to`) && use ops (`-> | && || ! w/ w/o`) && keep `path:line`, `symbol()`, flags, versions, root-cause/invariants verbatim. Ex: `fix(auth)|auth.py:42 refresh race -> mutex && retry=1 | verified:pytest`.
- **Batch, Chain & Subagents:** independent reads/greps in 1 turn | chain deterministic sequential cmds in 1 `run_command` w/ `&&` (`build && test && verify_universal.py --git-stat`, never split across extra inferences; only pause for user input or pending `EXTRA_REQUESTS.md`) | subagent replies <=20L.
- **Edit & Plan Diet:** minimal unique 1-2L `edit_file` anchor (merge gaps <=4L; split >5L; !re-indent >15L blocks -> extract `_inner()`; `python3 -c` only for >=15L mechanical edits) | `exit_plan_mode` plans in symbolic telegraphic EN (~30L) | !re-read in-context slices | cmd went async -> end turn w/ empty reply (0 text; await wake-up).
- **Termux ARM64 PRoot:** `parallel(heavy_tests || dotnet_build || git_push) -> FORBIDDEN` (run sequentially).
- **Mode (`auto` | `lean` | `strict` | `recon`):** precedence `PLANNER_MODE` > `profile.planner_mode` > `auto_mode.overrides`.
  - `auto` -> known cache/seed hit (`<1ms`, `0 net`) | unseen `modelName` -> safe `lean` + 1-time doc ctx -> AI runs `plan_tool.py model-mode set <model> <lean|strict> --why "..."` | offline -> safe `lean` w/ cooldown | `enter_plan_mode`/`exit_plan_mode` -> auto-pin `lean`.
  - `lean` -> `PreInvocation` auto-REQs + JIT + T2/T3 `AUDIT_EXISTING`/`CURATE_OSS` + T3 `SOTA_PREFLIGHT` (`MOD-SOTA-PREFLIGHT`) + `domains.*.lens` (`LENS|`, 420-char budget); `Tier<=1` >=4th file -> Blast Radius warn (`action:"force_ask"` opt-in once/turn).
  - `strict` -> Phase 0 `plan_tool.py init` BEFORE edits (`PLAN GATE`) && `plan_tool.py finish --evidence "..."`.
  - `recon` -> `plan_tool.py recon start [--scope "..."]` / `stop` / `status`: read-only forensic sweep blocking code edits (allows `.agents/docs/*`/`*.md`/`TASK_PLAN.md`) w/ `[BUG] | [UNWIRED] | [STRUCTURAL] | [UPGRADE] @ path:line`.
- **SOTA First-Principles Pre-Flight (`MOD-SOTA-PREFLIGHT`, Tier 3 mandatory):** Before implementing complex architectural/algorithmic/hardware features, run an internal 4-step challenge WITHOUT waiting for user brainstorming: (1) falsify naive/seeded roadmap assumptions vs current SOTA (literature/physics/OSS); (2) run an empirical/first-principles tournament (e.g., Math/Physics vs AI, hardware constraints vs software workarounds); (3) split execution planes & verify real hardware/runtime budgets before coding; (4) prove core invariants via a fast offline/synthetic golden benchmark before writing heavy production plumbing.
- **Token Diet:** `!read(transcript*.jsonl)` | files `>300L` -> `<=250L` slice via symbol map/`repo_map.py` | archive docs (`.agents/docs/archive/`, `archive_docs`, `HANDOFF` `ARCHIVE|`) `>150L` -> explicit `StartLine&EndLine <=120L` slice only | logs `>300L` -> `log_digest.py [--errors-only]` | `PROJECT_HISTORY.md` `L1-60` (guard `<=150L && <=28 KB`; `EXTERNAL_AI_SYNC.md <=48 KB`) | `ECO_MODE` drops secondary hints.
- **External API Docs (MCP):** Unknown external APIs/SDKs/flags -> consult `Context7` (3rd-party libs: `resolve-library-id`->`query-docs`) || `Google Developer Knowledge` (Android/Google/Cloud/Firebase/Flutter/Chrome/Go: `search_documents`/`answer_query`) BEFORE guessing.
- **Shift-Left & Anti-Loop:** secrets/conflicts/fail-`diff_rules` (`path_prefix`/`path_prefixes`)/recon/destructive `write_file` block pre-disk | `same_cmd_fails>=2 || same_file_edit_invocations>=4` -> Circuit Breaker stop | `undo-turn` reverts active turn.
- **Timeless Error Learning & Live Diagnostics:** recurring build/CI errors -> `plan_tool.py learn --from-log <file|-> --apply` (or `--fetch-live-ci --apply`); NEVER hardcode ephemeral SDK/OS/Action/pkg versions in `BUILD_LESSONS.md` (`verify_universal.py` auto-audits timelessness) | live uncached GitHub CI/runtime diagnostics -> `plan_tool.py live-diag --all` | live device/app bridge -> `live_bridge_client.py` (`--code` or `--wake` biometric Encrypt-then-MAC).
- **Autonomous Dual-Scope Self-Evolution & Higher-Version Sync (`MOD-SELF-EVOLVE`):** Whenever AI detects a workflow, diagnostic, guardrail, memory, or efficiency improvement during ANY task, auto-classify via `plan_tool.py evolve classify --desc "..."`:
  - `plugin-universal` -> implement directly in plugin (`scripts/`/`hooks/`/`rules/`/`tests/`) w/ zero host hardcoding && log in plugin `.agents/docs/EXTERNAL_AI_SYNC.md` + `CHANGELOG.md` + host `EXTERNAL_AI_SYNC.md` Plugin section.
  - `project-only` -> implement in host project && log in host `EXTERNAL_AI_SYNC.md` Project section + `PROJECT_HISTORY.md`.
  - `dual-project+plugin` -> universal engine in plugin + thin wrapper/config/UI in host project in SAME turn && update BOTH ledgers.
  - **Higher-Version Propagation & Retroactive Upgrade:** `plan_tool.py evolve sync-plugin [--apply]` compares embedded vs global plugin semver (`higher version ALWAYS wins`, never downgrades; `SessionStart` auto-syncs `embedded->global` when `plugin_evolution.auto_sync_higher_version: true` & retroactively migrates workspace profiles `v1..v3->v4` + stamps `plugin_version`).
- **Memory & Verify:** `!static("Current State")` | `handoff [--roadmap --wave --archive]` -> `WAVE_BRIDGE|` | prepend `PROJECT_HISTORY.md` | defer -> `SAVED_IDEAS.md` | clear `EXTRA_REQUESTS.md` pre-commit/push | `/btw` or main-agent queue intent -> auto-append `- REQ|<scope> -> <goal>` to `EXTRA_REQUESTS.md` (w/o asking) && reply ultra-terse (`<=2L`) | on `[DOCS_AUTO_MIGRATE]` -> losslessly convert listed legacy docs && run `plan_tool.py docs-migrated` | Stop runs fast static checks (`wiring_gate`, `key_parity_rules` w/ optional cross-file `target_path`, `diff_rules`, `BUILD_LESSONS.md` timeless audit, `code_weight_limits` anti-monolith guard, memory line+byte weight audit, plugin sync parity; `--build` runs multi-layer cascade w/ `on_upstream_fail_command` shadow + global diag dedup).
