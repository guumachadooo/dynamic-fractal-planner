- **Agent Files (Symbolic Telegraphic EN — mandatory):** ALL plugin/memory/plan files (`PROJECT_HISTORY.md`, `SAVED_IDEAS.md`, `EXTRA_REQUESTS.md`, `HANDOFF.md`, `BUILD_LESSONS.md`, `EXTERNAL_AI_SYNC.md`, `TASK_PLAN.md`, `AGENTS.md`/`SKILL.md`, `plan_tool.py` args) MUST use lossless dense symbolic EN regardless of chat language (never mangle user-facing UI/public docs): drop articles/copulas/filler (`a/the/is/please/in order to`) && use ops (`-> | && || ! w/ w/o`) && keep `path:line`, `symbol()`, flags, versions, root-cause/invariants verbatim. Ex: `fix(auth)|auth.py:42 refresh race -> mutex && retry=1 | verified:pytest`.
- **Batch, Chain & Subagents:** independent reads/greps in 1 turn | chain deterministic sequential cmds in 1 `run_command` w/ `&&` (`build && test && verify_universal.py --git-stat`, never split across extra inferences; only pause for user input or pending `EXTRA_REQUESTS.md`) | subagent replies <=20L.
- **Thin-Coordinator & Google-Only Model Routing (v5):** On T2/T3 (large/multi-file/long-running/verify tasks), keep main chat as thin coordinator (delegate bulk reads, multi-file edits, log inspection, & sequential PRoot builds/tests to max safe parallel `invoke_subagent` / `run_workflow` / `swarm`, keeping subagent replies `<=20L`) | **Single Verify Owner (`1-verify-owner`):** assign exactly ONE verify owner per wave for heavy builds/tests (`docs`/`flash_lite` subagents FORBIDDEN from running heavy build/test suites) | **Anti-Polling (`planner_guard_polling.py` + `planner_guard_command.py`):** NEVER poll via `schedule` timers, repeat `manage_task(status|list)` (<90s), repeat `ps aux | grep` (<120s), or `while/for+sleep` `gh run list|view` loops — end turn w/ empty reply for reactive wakeup (`NotificationTimeoutSeconds`) or run blocking `gh run watch --exit-status --compact` | **Adaptive Cubicle Pace (`pace=turbo|eco|normal`):** default `turbo` spins parallel isolated subagent cubicles across independent slices; `eco` still uses parallel cubicles whenever net-token-saving (small fresh contexts < bloated parent replay); `normal` uses standard adaptive routing | **fresh 1-shot & `!cmd-echo`:** subagents start fresh (0 parent ctx; `!swarm fork`), prefer fresh 1-shot subagents per slice (`!reuse` after heavy outputs or unrelated tasks; `send_message` ONLY for tiny stateful follow-ups <=2 turns), && send concise symbolic goal + target path/CLI verb ONLY (never paste long verbatim bash chains/scripts that subagent rewrites) | **Nested Sub-Subagents (`delegation.sub_subagent`):** when `allow_nesting:true` (default), subagents may spawn nested `invoke_subagent flash_lite`/`flash` || `swarm` `gemini-*-medium` (`gemini-4-hydrogen-medium` w/ `allow_medium_tier:true`) / `gemini-*-low` on non-complex slices whenever parallel/bulk slices save net tokens (`default_model:"flash_lite"`) | route explicit Google/Gemini models ONLY (`L0 trivial/file-find:flash_lite` | `L1-2 routine impl/audit/tests:flash` | `L3 complex DSP/arch/concurrency/root-cause:pro` [tag `[L3]`]; `!Claude/!Anthropic/!OpenAI/!ChatGPT/!o1-o4` — enforced by `planner_guard_delegation.py`).
- **Edit & Plan Diet:** minimal unique 1-2L `edit_file` anchor (merge gaps <=4L; split >5L; !re-indent >15L blocks -> extract `_inner()`; `python3 -c` only for >=15L mechanical edits) | `exit_plan_mode` plans in symbolic telegraphic EN (~30L) | !re-read in-context slices | cmd went async -> end turn w/ empty reply (0 text; await wake-up).
- **Termux ARM64 PRoot:** `parallel(heavy_tests || dotnet_build || git_push) -> FORBIDDEN` (run sequentially) | verify via `--fast` (1-proc ~20s; `!double --full` subprocess storm -> Android Phantom Process Killer).
- **Mode (`auto` | `lean` | `strict` | `recon`):** precedence `PLANNER_MODE` > `profile.planner_mode` > `auto_mode.overrides`.
  - `auto` -> known cache/seed hit (`<1ms`, `0 net`) | unseen `modelName` -> safe `lean` + 1-time doc ctx -> AI runs `plan_tool.py model-mode set <model> <lean|strict> --why "..."` | offline -> safe `lean` w/ cooldown | `enter_plan_mode`/`exit_plan_mode` -> auto-pin `lean`.
